# 学院学生综合服务与党团管理平台 — 用户使用手册

> 版本：V2.0  
> 适用对象：课程答辩演示、项目组成员、老师和测试同学  
> 适用环境：本地演示环境 / 远程演示环境 / 小程序体验版

---

## 一、文档说明

本文档用于说明“学院学生综合服务与党团管理平台”的使用方式，帮助使用者快速了解系统组成、运行入口、登录方式、主要功能以及典型使用流程。

本系统采用双端协同模式：

- 学生端使用微信小程序
- 管理端使用 Web 后台
- 服务端接口负责支撑双端之间的数据联动

为方便课程展示与日常联调，当前手册同时保留两种使用方式：

- 本地演示环境：适合答辩前本地部署、联调和功能验证
- 远程/体验版环境：适合通过服务器地址或小程序体验版进行访问

说明：

- 本地演示环境更适合开发、联调和答辩演示准备
- 远程/体验版环境更适合向老师或同学展示整体使用流程
- 不同环境下的可用账号、接口地址和部分数据可能存在差异，请以实际部署结果为准

## 二、系统简介

“学院学生综合服务与党团管理平台”是一套面向学院学生与管理老师的综合事务服务系统，目标是将通知查看、申请提交、审批处理、学生信息维护、党团流程管理、知识查询和模板下载等功能集中到统一平台中。

系统建设目标主要包括：

- 建立统一入口，减少学生在多个渠道之间切换
- 打通学生端与管理端，形成完整业务闭环
- 支撑通知、申请、流程、知识库等核心业务场景
- 为课程项目展示需求提供可演示、可验证的系统原型

- 查看通知公告

- 维护学生信息和重置密码
- 审批学生申请

## 五、运行方式说明

本项目支持两种运行方式：本地演示环境和远程/体验版环境。

### 5.1 本地演示环境

适用场景：

- 项目组内部联调
- 答辩前本地部署与演示准备
- 管理端与小程序端的同步验证

主要特征：

- 后端服务运行在本机
- Web 管理端通过本地开发服务器打开
- 小程序通过微信开发者工具导入运行

### 5.2 远程/体验版环境

适用场景：

- 向老师或同学演示
- 通过服务器地址访问管理端
- 通过微信体验版访问小程序

主要特征：

- 管理端通过远程服务器地址访问
- 小程序通过体验成员方式或部署好的体验版访问

## 六、本地演示环境使用方法

### 6.1 启动本地后端服务

进入项目的 `server` 目录，运行服务端程序。

示例命令：

```bash
python server.py
```

启动成功后，默认接口地址为：

- `http://localhost:3000/api`
- 文件地址：`http://localhost:3000/files`

说明：

- 若使用 Windows，需确保本机已正确安装 Python
- 若 3000 端口被占用，请先关闭冲突程序或修改端口配置

### 6.2 启动本地 Web 管理端

进入项目的 `admin-pc` 目录，执行以下命令：

```bash
npm install
npm run dev
```

启动成功后，浏览器打开终端输出的本地地址，例如：

- `http://localhost:5173/`

### 6.3 导入本地小程序项目

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择包含 `project.config.json` 的项目根目录
4. 导入后点击“编译”
5. 在“详情”或“本地设置”中勾选“不校验合法域名、web-view（业务域名）、TLS 版本”

说明：

- 项目应从根目录导入，不建议直接只导入 `miniprogram` 子目录
- 若使用真机预览，不应继续使用 `localhost`，需改为电脑的局域网 IP 地址

### 6.4 本地环境默认账号

本地 mock 演示环境下，常用账号如下：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |
| student1 | student123 | 学生 |
| student2 | student123 | 学生 |

说明：

- 本地环境中的预置账号以当前后端服务配置为准
- 若通过管理端添加新学生，初始密码可手动设置；若未填写，则默认密码通常为 `123456`

## 七、远程/体验版环境使用方法

### 7.1 访问远程 Web 管理端

在浏览器中打开项目组提供的服务器地址，例如：

- `http://10.10.0.22/`

然后使用项目组分配的管理员账号登录。

说明：

- 若远程服务器地址发生变化，请以项目负责人提供的最新地址为准
- 若远程服务器暂不可访问，可改用本地演示环境

### 7.2 访问小程序体验版

若已配置小程序体验版，可按以下方式使用：

1. 将自己的微信号发送给项目负责人
2. 由项目负责人在小程序后台添加体验成员
3. 微信收到邀请后，在小程序列表中打开体验版
4. 使用项目组提供的测试账号登录

说明：

- 体验版账号、体验时间和体验范围以项目负责人实际配置为准
- 若体验版不可用，建议改用微信开发者工具打开本地项目

### 7.3 远程环境账号说明

远程环境账号可能与本地环境不同，建议使用项目组统一分配的账号。

若老师或测试同学只需要演示主要功能，可优先提供以下两类账号：

- 管理员账号：用于发布通知、审批申请、维护知识条目
- 学生账号：用于查看通知、提交申请、查询进度、搜索知识

## 八、Web 管理端使用说明

### 8.1 登录

在浏览器中打开管理端地址后，输入管理员用户名和密码，点击“登录”。

登录成功后将进入后台首页或默认业务页面。

### 8.2 通知管理

在“通知管理”页面，管理员可进行以下操作：

- 新建通知
- 编辑通知
- 删除通知
- 查看通知详情
- 查看通知已读/未读统计

适用场景：

- 发布学院通知
- 查看通知触达效果

### 8.3 学生管理

在“学生管理”页面，管理员可进行以下操作：

- 添加学生
- 编辑学生信息
- 删除学生
- 按年级、专业等条件筛选
- 重置学生密码

说明：

- 新增学生时需至少填写学号和姓名
- 初始密码可手动设置；若不填写，则默认密码通常为 `123456`
- 重置密码后的具体结果以系统提示为准

### 8.4 审批工作台

在“审批工作台”页面，管理员可查看学生提交的申请，并进行处理：

- 通过
- 驳回
- 要求补交

适用场景：

- 证明申请审批
- 请假申请审批
- 其他基础事务申请处理

### 8.5 党团流程配置

在“党团流程配置”页面，管理员可进行以下操作：

- 维护入党/入团流程阶段
- 编辑阶段说明和材料要求
- 更新学生当前阶段进度

说明：

- 该模块更适合作为流程演示与联调验证使用
- 不同环境下的数据同步效果可能略有差异

### 8.6 知识库管理

在“知识库管理”页面，管理员可进行以下操作：

- 新建知识条目
- 编辑知识条目
- 删除知识条目
- 上传模板文件

适用场景：

- 维护政策制度
- 沉淀常见问题与答疑内容

### 8.7 数据导入导出

在“数据导入导出”页面，管理员可进行以下操作：

- 下载学生信息导入模板
- 上传 CSV 文件导入学生信息
- 导出审批记录
- 导出文件清单

说明：

- 当前版本支持基础的导入导出演示与联调验证
- 实际导入结果与字段要求以页面提示为准

### 8.8 操作日志

在“操作日志”页面，可查看后台操作记录，内容通常包括：

- 操作时间
- 操作人
- 动作类型
- 对象类型
- IP 信息

## 十、典型使用流程

本节列出系统中最常见、最适合演示的几个典型流程。

### 10.1 流程一：查看通知

1. 学生登录小程序
2. 进入“通知”页面
3. 查看通知列表
4. 点击某条通知查看详情
5. 返回列表后查看阅读状态变化

适用说明：

- 该流程适合快速演示学生端通知使用方式

### 10.2 流程二：管理员发布通知

1. 管理员登录 Web 管理端
2. 进入“通知管理”
3. 点击“新建通知”
4. 输入标题和内容
5. 保存或发布通知

适用说明：

- 在具备完整联动环境时，可与学生端通知查看结合演示

### 10.3 流程三：学生提交申请

1. 学生登录小程序
2. 进入“服务”页面
3. 选择“证明申请”或“请假申请”
4. 填写申请标题、说明等信息
5. 点击提交
6. 在“我的申请”中查看记录

### 10.4 流程四：管理员处理申请

1. 管理员登录 Web 管理端
2. 进入“审批工作台”
3. 查看待处理申请
4. 选择通过、驳回或要求补交
5. 保存处理结果

### 10.5 流程五：知识查询

1. 学生登录小程序
2. 进入“服务”页面，打开“政策搜索”
3. 输入关键词或选择标签
4. 查看知识条目列表
5. 点击进入详情页

## 十一、常见问题

### 11.1 管理端打开后无法登录

可能原因：

- 后端服务未启动
- 本地代理地址配置错误
- 账号密码输入错误

建议处理：

- 确认本地后端已启动
- 确认管理端代理目标地址与后端端口一致
- 优先使用手册中给出的默认账号测试

### 11.2 小程序提示网络连接失败

可能原因：

- 后端服务未启动
- 小程序接口地址未切换到当前环境
- 真机预览时仍使用 `localhost`

建议处理：

- 检查小程序配置中的接口地址
- 模拟器使用 `localhost` 或 `127.0.0.1`
- 真机调试时改为电脑局域网 IP

### 11.3 小程序提示域名不合法

建议处理：

- 在微信开发者工具中勾选“不校验合法域名、web-view（业务域名）、TLS 版本”

### 11.4 新增学生后无法立即在小程序端完整显示信息

说明：

- 在不同演示环境下，学生基础信息回显能力可能不同
- 若当前环境以本地联调为主，建议优先验证登录能力和核心流程，不强制要求所有扩展字段完整联动

### 11.5 某些功能页面能打开，但数据不完整

说明：

- 当前版本同时兼顾课程演示与联调验证，部分模块在不同环境中数据完整度可能不同
- 建议优先演示通知、登录、申请、审批、知识查询等核心流程
