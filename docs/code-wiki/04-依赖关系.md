# 04 依赖关系

## 运行时依赖（强依赖）

### 微信小程序运行环境

- 微信小程序基础能力（`App` / `Page` / `wx.*` API）。
- Storage：`wx.getStorageSync` / `wx.setStorageSync` / `wx.removeStorageSync`，见 [storage.js](file:///workspace/demoApp/utils/storage.js#L6-L54)。
- 网络：`wx.request`，见
  - 登录页演示请求 [login.js](file:///workspace/demoApp/pages/login/login.js#L84-L110)
  - 待办页 CRUD [todos.js](file:///workspace/demoApp/pages/todos/todos.js#L60-L118)
  - Network 专项页 [network-demo.js](file:///workspace/demoApp/pages/network-demo/network-demo.js#L12-L56)

### Node.js 运行环境（本地服务端）

服务端仅使用 Node.js 内置模块：

- `http`：创建 HTTP 服务器与路由分发，见 [server/index.js](file:///workspace/demoApp/server/index.js#L10-L165)
- `URL`：解析 query 参数，见 [getNicknameFromUrl](file:///workspace/demoApp/server/index.js#L28-L35)
- `Buffer`：合并 body chunks，见 [readJsonBody](file:///workspace/demoApp/server/index.js#L49-L59)

## 外部服务依赖（教学用）

项目使用 `httpbin.org` 作为可回显的公网接口，便于 Network 面板观察：

- `POST https://httpbin.org/post`：登录页 Network 演示，见 [login.js](file:///workspace/demoApp/pages/login/login.js#L12-L110)
- `GET https://httpbin.org/get`：Network 练习页成功请求，见 [network-demo.js](file:///workspace/demoApp/pages/network-demo/network-demo.js#L1-L33)

注意：

- 这类演示请求不应携带真实用户密码；本项目仅用于课堂/本地演示。
- 真机预览/上架时需要配置合法域名；开发者工具可通过设置绕过校验（见下一节）。

## 工程与工具依赖（开发期）

### 微信开发者工具配置

配置文件：[demoApp/project.config.json](file:///workspace/demoApp/project.config.json)

关键配置项：

- `setting.urlCheck: false`：允许在开发者工具中不校验合法域名（便于本地/教学演示 `httpbin`、`localhost` 等）。
- `compileType: "miniprogram"`：项目类型为小程序。
- `libVersion`：项目配置中记录的小程序基础库版本（用于开发者工具模拟环境）。

### Postman（可选）

用于对照验证服务端接口输出与小程序一致性（项目 README 中给出了示例请求），见 [demoApp/README.md](file:///workspace/demoApp/README.md#L28-L41)。

## 数据与存储依赖（键名约定）

Storage key 约定集中在 [storage.js](file:///workspace/demoApp/utils/storage.js#L1-L77)：

- `users:v1`：用户表 `{ [nickname]: { passwordHash, createdAt } }`
- `session:v1`：当前会话 `{ nickname, loginAt }`
- `todos:v1:<nickname>`：旧版本地待办（仅用于迁移到服务端）

服务端内存 store 结构见 [server/index.js](file:///workspace/demoApp/server/index.js#L12-L42)：

- `todoStore[nickname] = Array<{ id, text, createdAt }>`
