# 04 依赖关系

本仓库的依赖分为两类：目标系统（按需求/规划）的技术栈依赖，以及当前仓库已存在原型（demoApp）的实际依赖。

## 目标系统（按需求/规划）的依赖

来源：

- 目标形态与范围：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L14-L19)
- 技术选型建议：[四人分工与整体流程计划.md](file:///workspace/四人分工与整体流程计划.md#L9-L13)

### 学生端（微信小程序）

- 框架：建议 uni-app（Vue 语法）
- 能力：微信登录、文件下载/上传、消息中心、路由与页面状态管理

### 管理端（PC Web）

- 框架：Vue 3
- UI：Element Plus（表格/表单/导入导出/审批工作台）

### 后端服务

- 运行时：Node.js
- 语言：TypeScript（建议）
- 框架：Express（或 NestJS）
- 能力依赖：
  - RBAC 权限与鉴权（token）
  - 文件处理（Excel 导入导出、PDF 生成、模板渲染）
  - 定时任务（节点提醒、异步任务状态）
  - 日志/审计与敏感信息加密

### 数据库

- Kingbase（按 PostgreSQL 方式连接与建模）

## 当前仓库原型（demoApp）的实际依赖

### 小程序端

目录：[demoApp](file:///workspace/demoApp)

- 原生微信小程序（WXML/WXSS/JS + `App`/`Page` + `wx.*`）
- 本地存储：`wx.getStorageSync/setStorageSync`，见 [demoApp/utils/storage.js](file:///workspace/demoApp/utils/storage.js#L6-L54)
- 网络请求：`wx.request`，见
  - 登录页演示请求 [demoApp/pages/login/login.js](file:///workspace/demoApp/pages/login/login.js#L84-L110)
  - 待办 CRUD [demoApp/pages/todos/todos.js](file:///workspace/demoApp/pages/todos/todos.js#L60-L188)

### 服务端

目录：[demoApp/server](file:///workspace/demoApp/server)

- Node.js 内置模块：`http`、`URL`、`Buffer`，见 [demoApp/server/index.js](file:///workspace/demoApp/server/index.js#L10-L62)
- 内存存储：服务端重启会清空数据（教学演示用）

### 外部网络依赖（教学用）

- `httpbin.org`
  - `POST https://httpbin.org/post`：登录页 Network 演示请求，见 [demoApp/pages/login/login.js](file:///workspace/demoApp/pages/login/login.js#L12-L110)
  - `GET https://httpbin.org/get`：Network 练习页成功请求，见 [demoApp/pages/network-demo/network-demo.js](file:///workspace/demoApp/pages/network-demo/network-demo.js#L1-L33)

### 工程工具依赖

- 微信开发者工具项目配置：[demoApp/project.config.json](file:///workspace/demoApp/project.config.json)
  - `setting.urlCheck: false`：开发者工具中可绕过合法域名校验（便于 demo 环境）
