# 03 关键组件与函数

本项目目前没有传统意义上的“类”（Class）体系，核心逻辑主要以 Vue SFC 中的组合式 API（`<script setup lang="ts">`）函数存在。

## 启动入口

### `createApp(App).use(...).mount(...)`

- 位置： [main.ts](file:///workspace/admin-pc/src/main.ts#L1-L10)
- 职责：
  - `createApp(App)` 创建根实例
  - `app.use(ElementPlus)` 注入 Element Plus 组件/能力
  - `app.use(router)` 注入路由
  - `app.mount('#app')` 挂载到 DOM

## 路由定义

### `createRouter({ history, routes })`

- 位置： [router/index.ts](file:///workspace/admin-pc/src/router/index.ts#L1-L28)
- 关键点：
  - 根路径 `/` 使用 Layout 壳组件并 `redirect: '/notice'`
  - 业务页面懒加载：`component: () => import(...)`

## 布局壳：`Layout.vue`

### `menuItems`

- 位置： [Layout.vue](file:///workspace/admin-pc/src/views/Layout.vue#L8-L11)
- 类型：`Array<{ path: string; title: string }>`
- 用途：侧边栏菜单渲染与导航目标定义

### `onMenuClick(path: string)`

- 位置： [Layout.vue](file:///workspace/admin-pc/src/views/Layout.vue#L13-L15)
- 输入：路由路径（如 `/notice`）
- 行为：`router.push(path)` 触发导航

## 通知管理页：`NoticeManage.vue`

### `interface Notice`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L6-L12)
- 字段：
  - `id: number`：当前实现用 `Date.now()` 生成
  - `title/content: string`
  - `status: '已发布' | '未发布'`：当前保存时固定为 `未发布`
  - `publishTime: string`：保存时由 `toLocaleString('zh-CN', ...)` 生成

### `noticeList: Ref<Notice[]>`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L15-L37)
- 用途：表格数据源（当前为 Mock 初始值）
- 变更点：
  - 新增：`noticeList.value.unshift(...)`（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L74-L86)）
  - 删除：`noticeList.value.splice(index, 1)`（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L92-L98)）

### 弹窗状态：`dialogVisible / dialogTitle`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L39-L42)
- 用途：控制 `<el-dialog v-model="dialogVisible">` 以及标题显示（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L128-L130)）

### 表单状态：`form`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L44-L48)
- 类型：`{ title: string; content: string }`（通过 `reactive`）
- 用途：双向绑定到 `<el-input v-model="form.title|content">`（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L131-L141)）

### `handleCreate()`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L50-L55)
- 行为：
  - 将弹窗标题置为“新建通知”
  - 清空表单
  - 打开弹窗

### `handleEdit(row: Notice)`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L57-L62)
- 行为：
  - 将弹窗标题置为“编辑通知”
  - 将表格行数据回填到表单
  - 打开弹窗
- 当前限制：
  - `handleSave()` 并不基于“编辑态”更新原记录，而是始终新增一条（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L64-L90)）

### `handleSave()`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L64-L90)
- 行为：
  - 校验 `title/content` 非空，否则 `ElMessage.warning(...)`
  - 新增一条通知到列表头部（id 为时间戳、状态默认为未发布、发布时间为本地化字符串）
  - 关闭弹窗并提示 `ElMessage.success('通知已保存')`

### `handleDelete(row: Notice)`

- 位置： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L92-L98)
- 行为：
  - `findIndex` 定位 `id` 相等的记录，存在则删除并提示“已删除”
