# 02 主要模块职责

本节以需求文档的一期范围为主（模块 A–E），并补充“仓库现有 demoApp 原型”。

## 模块A：政策/制度知识库与标准问答

来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L71-L83)

- 学生端
  - 搜索：按关键词查询标题/关键词/摘要
  - 详情：展示标准答复 + 关联文件/官方链接
  - 模板下载：常用 Word/Excel 模板下载
- 管理端
  - 条目维护：新增/编辑/下线，维护关键词、适用人群、附件
  - 版本信息：记录更新时间与维护人
- 约束
  - 以标准答案/链接为主，避免未确认的推测性结论

## 模块B：党团事务流程管理（入党/入团）

来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L84-L94)

- 学生端
  - 流程查看：全流程阶段列表 + 阶段说明
  - 个人进度：当前阶段、历史动作、待办材料
  - 提醒接收：站内消息提醒并可跳转详情
- 管理端
  - 流程配置：阶段（名称、说明、材料、时限、负责人角色）
  - 学生进度管理：查询与更新阶段、记录关键动作
  - 提醒规则配置：节点与触发规则配置（时间点/条件/对象）

## 模块C：通知与精准推送

来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L95-L104)

- 管理端
  - 通知创建：标题、正文、附件
  - 标签与人群规则：年级/专业/毕业生/政治面貌等标签口径（参考 [党团老师需提供资料清单.md](file:///workspace/党团老师需提供资料清单.md#L8-L12)）
  - 发布与记录：发送记录、已读统计
  - 批量导入：按模板导入通知并做字段校验
- 学生端
  - 通知中心：列表、详情、已读状态

## 模块D：电子证明生成与审批

来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L105-L115)

- 学生端
  - 申请提交：选择事项、表单填写、附件上传
  - 进度查询：状态、审批意见与时间
  - 结果获取：通过后下载结果文件（PDF/系统生成文件）
- 管理端
  - 事项配置：字段/附件清单、模板字段映射与落款规范
  - 审批工作台：待办/已办、通过/驳回/补交、意见留痕
  - 归档导出：审批记录导出、结果文件导出

## 模块E：导入导出

来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L116-L122)

- 学生基础数据导入：模板化导入、错误行定位、结果报告
- 通知批量导入：模板化导入与校验
- 审批记录导出：按时间/事项筛选导出 Excel
- 文件批量导出：证明/结果文件导出与打包

## 横切模块（建议纳入后端基础设施）

需求中隐含但必须落地的通用能力：

- 鉴权与 RBAC：最小权限、按角色控制可见范围（见 [需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L27-L31)）
- 操作留痕/审计：创建/修改/审批/导入导出需记录操作者与时间（见同段落）
- 敏感数据处理：联系方式、身份证号等敏感字段加密存储与受控展示（见 [需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L135-L138)）
- 定时任务：节点提醒、导入导出任务状态维护

## 仓库现有代码（demoApp 原型）

目录 [demoApp](file:///workspace/demoApp) 不是目标系统实现，但包含可运行的最小闭环示例：

- 登录页：本地用户表 + 会话（Storage），见 [demoApp/pages/login/login.js](file:///workspace/demoApp/pages/login/login.js)
- 待办页：以本地 Node 服务为数据源的 CRUD，见 [demoApp/pages/todos/todos.js](file:///workspace/demoApp/pages/todos/todos.js)
- Network 练习页：成功/失败请求对照，见 [demoApp/pages/network-demo/network-demo.js](file:///workspace/demoApp/pages/network-demo/network-demo.js)
- 本地 API 服务：`GET/POST/DELETE` 待办接口，见 [demoApp/server/index.js](file:///workspace/demoApp/server/index.js)
