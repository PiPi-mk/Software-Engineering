# 05 运行与构建

## 前置条件

- 已安装 Node.js 与 npm
- 在子项目目录执行命令：`/workspace/admin-pc`

## 安装依赖

在 `admin-pc` 目录下执行：

```bash
npm install
```

## 本地开发（热更新）

```bash
npm run dev
```

脚本来源： [package.json](file:///workspace/admin-pc/package.json#L6-L10)（`dev: vite`）。

## 构建（生产产物）

```bash
npm run build
```

该命令包含两步（脚本来源同上）：

1. `vue-tsc -b`：类型检查
2. `vite build`：打包构建

默认构建产物目录为 `admin-pc/dist/`（Vite 默认行为；若后续在 Vite 配置中自定义输出目录，以配置为准）。

## 本地预览构建产物

```bash
npm run preview
```

脚本来源： [package.json](file:///workspace/admin-pc/package.json#L6-L10)（`preview: vite preview`）。

## 常见运行路径

- 默认首页访问 `/` 会被重定向到 `/notice`：见 [router/index.ts](file:///workspace/admin-pc/src/router/index.ts#L6-L24)
