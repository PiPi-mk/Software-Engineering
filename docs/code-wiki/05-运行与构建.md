# 05 运行与构建

## 本地运行（推荐流程）

### 1) 启动本地待办服务端

在仓库根目录执行：

```bash
node demoApp/server/index.js
```

服务默认监听 `3000` 端口，重启服务会清空内存数据。接口详情见 [demoApp/README.md](file:///workspace/demoApp/README.md#L28-L41) 与 [server/index.js](file:///workspace/demoApp/server/index.js#L1-L170)。

### 2) 在微信开发者工具导入并运行小程序

- 打开微信开发者工具 → 导入项目
- 目录选择：`demoApp/`（该目录下包含 `app.js/app.json`）
- AppID：可使用测试号/无 AppID（按你的环境选择）
- 运行后先在登录页输入昵称、密码完成登录

## 调试与验证

### Network 面板练习（登录页演示请求）

位置：[demoApp/pages/login/login.js](file:///workspace/demoApp/pages/login/login.js#L64-L111)

建议步骤：

1. 开发者工具切到 调试器 → Network，并清空列表。
2. 在登录页输入昵称与密码，点击“登录”。
3. 查看对 `https://httpbin.org/post` 的请求与请求体。

### Network 专项页（成功/失败对照）

入口：登录页点击 “Network 面板练习（wx.request）”，见 [login.wxml](file:///workspace/demoApp/pages/login/login.wxml#L31-L33)

页面：[demoApp/pages/network-demo/network-demo.wxml](file:///workspace/demoApp/pages/network-demo/network-demo.wxml)

- 成功：`GET https://httpbin.org/get`
- 失败：无效域名触发 `wx.request.fail`（用于观察错误）

### Postman 对照验证（可选）

在服务端启动后，可用 Postman 直接请求本地接口，与小程序待办列表对照：

- `GET http://localhost:3000/todo/list?nickname=zhangsan`

## 常见问题

### 1) 待办页提示请求失败/空列表

排查顺序：

- 确认已启动 `node demoApp/server/index.js`
- 确认端口未被占用（默认 3000）
- 确认小程序端请求地址为 `http://localhost:3000`（见 [todos.js](file:///workspace/demoApp/pages/todos/todos.js#L8)）

### 2) 外网请求被拦截（httpbin）

开发者工具环境下通常通过项目设置绕过校验：

- `project.config.json` 中 `setting.urlCheck: false`，见 [project.config.json](file:///workspace/demoApp/project.config.json#L2-L6)

真机调试/预览时，需要按微信官方要求配置 request 合法域名或使用开发环境配置。
