# 00 项目概览

## 仓库边界

- 仓库根目录仅包含一个应用子项目：`admin-pc/`（管理端 PC 前端）。
- 未发现后端服务、数据库模型、API 客户端封装、测试框架配置或 README 文档（以当前仓库内容为准）。

## 技术栈

- 构建工具：Vite（见 [vite.config.ts](file:///workspace/admin-pc/vite.config.ts)）
- 前端框架：Vue 3（见 [package.json](file:///workspace/admin-pc/package.json#L11-L15)）
- 路由：Vue Router 4（见 [router/index.ts](file:///workspace/admin-pc/src/router/index.ts)）
- UI：Element Plus（见 [main.ts](file:///workspace/admin-pc/src/main.ts#L1-L10) 与 [package.json](file:///workspace/admin-pc/package.json#L11-L15)）
- 语言：TypeScript（见 [tsconfig.app.json](file:///workspace/admin-pc/tsconfig.app.json)）

## 当前功能范围

- 通知管理（页面级 Mock CRUD）
  - 路径：`/notice`
  - 页面： [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue)
  - 说明：列表数据在前端内存中维护；保存时直接 `unshift` 到列表头部；不区分新增与更新；无后端接口对接。
- 审批工作台（占位页）
  - 路径：`/approval`
  - 页面： [ApprovalWorkbench.vue](file:///workspace/admin-pc/src/views/ApprovalWorkbench.vue)
