# 00 项目概览

## 目标系统是什么

目标系统为「学院学生综合服务与党团管理平台」，面向学生与党团相关管理角色，提供一站式入口完成：

- 查询：政策/制度知识库、标准问答、文件与模板下载
- 流程：入党/入团等党团事务流程可视化与个人进度追踪
- 通知：标签化与人群规则的精准通知推送、已读统计
- 审批：证明/申请线上提交与多级审批留痕、结果文件生成与归档导出
- 数据：以 Excel/Word/PDF 导入导出为主要闭环方式，不直接依赖校级系统接口

项目总体需求描述详见：

- [需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md)
- [需求文档-甲方沟通版B.md](file:///workspace/需求文档-甲方沟通版B.md)

## 角色与权限（高层）

需求文档给出的核心角色：

- 学生：查询公共内容、提交申请、查看本人进度与结果
- 党团管理员（老师/助教）：维护流程与内容、处理审批、发布通知、导入导出、统计
- 系统管理员：系统配置、角色分配、审计查看

权限原则与敏感信息要求见 [需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L21-L31)。

## 当前仓库内容与实现状态

1. 项目总体文档（需求与协作计划）

因此，本 Code Wiki 在描述“目标系统架构与模块”时以仓库文档为准，同时在“现有代码”部分会标注 demoApp 中已经存在的实现点，避免把规划内容误认为已落地代码。
