# 00 项目概览

## 项目目标

本项目用于教学/演示微信小程序开发的基础能力，重点覆盖：

- 登录与会话：使用本地 Storage 维护用户与会话（Demo 逻辑：新昵称自动注册，已有昵称做密码校验）。
- 待办 CRUD：以本地 Node.js 服务端内存数据为唯一数据源，小程序与 Postman 可看到同一份列表。
- Network 面板练习：通过 `wx.request` 触发可观察的成功/失败请求，便于在开发者工具中学习抓包与排错。

项目入口与说明见 [demoApp/README.md](file:///workspace/demoApp/README.md)。

## 仓库结构

仓库根目录仅包含一个业务项目目录 `demoApp/`（微信小程序项目根）。

- 小程序根：`demoApp/`
  - 全局入口与配置
    - [app.js](file:///workspace/demoApp/app.js)：小程序启动逻辑（检查会话并跳转）
    - [app.json](file:///workspace/demoApp/app.json)：页面注册（等价于路由表）与窗口配置
    - [app.wxss](file:///workspace/demoApp/app.wxss)：全局样式基座
  - 页面（Page）
    - [pages/login](file:///workspace/demoApp/pages/login)：登录页（含 Network 请求演示入口）
    - [pages/todos](file:///workspace/demoApp/pages/todos)：待办页（服务端数据源 + 旧本地数据迁移）
    - [pages/network-demo](file:///workspace/demoApp/pages/network-demo)：Network 成功/失败对照页
  - 工具
    - [utils/storage.js](file:///workspace/demoApp/utils/storage.js)：Storage 读写封装、会话与用户表、旧待办数据
  - 本地服务端（供小程序请求 & Postman 调试）
    - [server/index.js](file:///workspace/demoApp/server/index.js)：Node.js `http` 服务器，提供待办 CRUD 接口
  - 工程配置
    - [project.config.json](file:///workspace/demoApp/project.config.json)：微信开发者工具项目配置（含 `urlCheck: false`）

## 运行时组件

从运行时角度，项目由两部分组成：

1. 微信小程序（客户端）
   - UI：WXML/WXSS
   - 逻辑：页面 JS（`Page({...})`）与全局 `App({...})`
   - 存储：`wx.getStorageSync/setStorageSync`（用户表、会话、旧待办）
2. Node.js 待办服务（服务端）
   - 内存存储：按 `nickname` 隔离的 `todoStore`（重启服务会清空）
   - REST 风格接口：`GET /todo/list`、`POST /todo/add`、`POST /todo/sync`、`DELETE /todo/item`
