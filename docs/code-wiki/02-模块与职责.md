# 02 模块与职责

本项目按“页面 + 工具 + 服务端”的方式组织模块。

## 页面模块（客户端）

### 登录页（pages/login）

路径：

- 逻辑：[demoApp/pages/login/login.js](file:///workspace/demoApp/pages/login/login.js)
- 视图：[demoApp/pages/login/login.wxml](file:///workspace/demoApp/pages/login/login.wxml)
- 样式：[demoApp/pages/login/login.wxss](file:///workspace/demoApp/pages/login/login.wxss)
- 页面配置：[demoApp/pages/login/login.json](file:///workspace/demoApp/pages/login/login.json)

职责：

- 采集昵称与密码输入，并进行必要的非空校验。
- 触发一次 Network 教学请求（`wx.request` 到 `httpbin`），便于在开发者工具 Network 面板观察。
- 执行本地登录/注册逻辑：维护用户表与会话，并跳转到待办页。
- 提供 Network 专项练习页的入口。

### 待办页（pages/todos）

路径：

- 逻辑：[demoApp/pages/todos/todos.js](file:///workspace/demoApp/pages/todos/todos.js)
- 视图：[demoApp/pages/todos/todos.wxml](file:///workspace/demoApp/pages/todos/todos.wxml)
- 样式：[demoApp/pages/todos/todos.wxss](file:///workspace/demoApp/pages/todos/todos.wxss)
- 页面配置：[demoApp/pages/todos/todos.json](file:///workspace/demoApp/pages/todos/todos.json)

职责：

- 校验会话（无会话则强制回到登录页）。
- 以服务端为唯一数据源拉取/展示待办列表。
- 当服务端列表为空且本地存在旧待办时，自动迁移旧数据到服务端（`POST /todo/sync`），并清空旧本地键。
- 提供新增与删除待办的 UI 与请求逻辑。
- 提供退出登录功能（清会话并回到登录页）。

### Network 练习页（pages/network-demo）

路径：

- 逻辑：[demoApp/pages/network-demo/network-demo.js](file:///workspace/demoApp/pages/network-demo/network-demo.js)
- 视图：[demoApp/pages/network-demo/network-demo.wxml](file:///workspace/demoApp/pages/network-demo/network-demo.wxml)
- 样式：[demoApp/pages/network-demo/network-demo.wxss](file:///workspace/demoApp/pages/network-demo/network-demo.wxss)
- 页面配置：[demoApp/pages/network-demo/network-demo.json](file:///workspace/demoApp/pages/network-demo/network-demo.json)

职责：

- 提供 2 个最小可复现按钮：一个成功请求、一个预期失败请求。
- 用 `lastResult` 回显最近一次结果，帮助理解 `success/fail` 分支与状态码/错误信息。

## 工具模块（客户端）

### Storage 工具（utils/storage.js）

路径：[demoApp/utils/storage.js](file:///workspace/demoApp/utils/storage.js)

职责：

- 封装 Storage 的容错读写：`safeGet/safeSet`（避免 storage 异常导致页面崩溃）。
- 管理用户表：`loadUsers/saveUsers`，并通过 `hashPassword` 做 Demo 级别的“非明文存储”。
- 管理会话：`getSession/setSession/clearSession`。
- 管理旧版待办（迁移用）：`loadTodos/saveTodos`，以 `todos:v1:<nickname>` 作为 key。

## 服务端模块（server/index.js）

路径：[demoApp/server/index.js](file:///workspace/demoApp/server/index.js)

职责：

- 提供待办 CRUD 接口（按 nickname 隔离），供小程序与 Postman 调试共用。
- 处理 CORS、OPTIONS 预检与 JSON body 解析。
- 维护内存态 `todoStore`（重启清空），简化演示成本。
