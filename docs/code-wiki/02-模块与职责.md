# 02 模块与职责

## 目录结构

仓库：

```text
/workspace
  ├─ admin-pc/                 前端应用（Vite + Vue3 + TS）
  │  ├─ public/                静态资源（原样拷贝）
  │  ├─ src/
  │  │  ├─ router/             路由模块
  │  │  ├─ views/              页面与布局
  │  │  ├─ App.vue             根组件
  │  │  └─ main.ts             启动入口
  │  ├─ index.html             HTML 入口
  │  ├─ vite.config.ts         Vite 配置
  │  ├─ tsconfig*.json         TypeScript 配置
  │  └─ package.json           依赖与脚本
  └─ docs/code-wiki/           本 Wiki 文档
```

## 装配与入口

### `admin-pc/index.html`

- 职责：Vite 默认 HTML 入口；提供挂载点 `#app`；以 ESM 方式加载 `src/main.ts`
- 关键点：`<script type="module" src="/src/main.ts"></script>`（见 [index.html](file:///workspace/admin-pc/index.html#L9-L12)）

### `admin-pc/src/main.ts`

- 职责：创建 Vue 应用并注册插件
- 依赖：
  - `vue` 的 `createApp`
  - Element Plus（及其全局样式）
  - Vue Router
- 代码入口： [main.ts](file:///workspace/admin-pc/src/main.ts#L1-L10)

### `admin-pc/src/App.vue`

- 职责：应用根组件；仅提供顶层 `<router-view />`
- 代码入口： [App.vue](file:///workspace/admin-pc/src/App.vue#L1-L3)

## 路由模块：`admin-pc/src/router`

### `router/index.ts`

- 职责：
  - 建立 `createWebHistory()` 的 history
  - 定义路由树与懒加载页面
  - 以 `Layout.vue` 作为壳组件，将业务页面作为其子路由渲染
- 路由条目：
  - `/notice`：通知管理（`meta.title = 通知管理`）
  - `/approval`：审批工作台（`meta.title = 审批工作台`）
- 代码入口： [index.ts](file:///workspace/admin-pc/src/router/index.ts#L1-L28)

## 视图模块：`admin-pc/src/views`

### `views/Layout.vue`

- 职责：
  - 提供左侧侧边栏导航与右侧内容区
  - 通过 `useRoute()` 高亮当前菜单项
  - 通过 `router.push(path)` 进行导航
- 关键点：
  - 菜单配置：`menuItems`（见 [Layout.vue](file:///workspace/admin-pc/src/views/Layout.vue#L8-L11)）
  - 导航函数：`onMenuClick(path)`（见 [Layout.vue](file:///workspace/admin-pc/src/views/Layout.vue#L13-L15)）

### `views/NoticeManage.vue`

- 职责：通知列表的展示与（Mock）增删改流程
- 页面能力：
  - 列表展示：`<el-table :data="noticeList" />`（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L109-L126)）
  - 新建/编辑弹窗：`<el-dialog v-model="dialogVisible" />`（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L128-L147)）
  - 表单校验（简化）：保存时做 `title/content` 非空校验（见 [NoticeManage.vue](file:///workspace/admin-pc/src/views/NoticeManage.vue#L64-L72)）

### `views/ApprovalWorkbench.vue`
