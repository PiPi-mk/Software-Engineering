# 03 关键领域对象与接口

本节以“需求文档中明确列出的核心数据对象”为准，并给出建议的接口边界与职责划分。当前仓库尚未实现这些领域对象；若后续开始落地，可将本节作为建表与 API 设计的起点。

核心数据对象来源：[需求文档-小组需求说明V1.md](file:///workspace/需求文档-小组需求说明V1.md#L123-L134)。

## 关键领域对象（建议定义）

### 用户与角色（User / Role）

职责：

- 统一承载鉴权主体（学生/管理员/系统管理员）
- 绑定学生身份信息（学号、姓名）与权限角色

建议关键字段：

- `id`
- `role`（student / staff / sysadmin）
- `wechatOpenId/unionId`（或其他登录标识）
- `studentId`（学号，学生角色必填）
- `status`（active/disabled）
- `createdAt/updatedAt`

### 学生基础信息（StudentProfile）

职责：

- 承载导入的基础数据与标签口径，为“通知精准推送、人群规则、敏感字段控制”提供依据

建议关键字段（按需求口径）：

- `studentId`、`name`、`grade`、`major`、`className`
- `politicalStatus`（政治面貌）
- `phone/email`（敏感）

### 知识库条目（KnowledgeBaseArticle）

职责：

- 标准问答与制度政策条目管理

建议关键字段：

- `id`、`title`、`keywords[]`、`summary`
- `content`（标准答复）
- `links[]`（官方链接）
- `attachments[]`（模板/文件）
- `audienceRule`（适用人群）
- `status`（draft/published/offline）
- `updatedBy/updatedAt`

### 流程定义与阶段（ProcessDefinition / ProcessStage）

职责：

- 定义入党/入团等线性流程的阶段序列、材料清单、时限与负责人角色

建议关键字段：

- `processType`（partyJoin/leagueJoin 等）
- `stages[]`：`stageId/name/order/description/materials/dueInDays/ownerRole`

### 学生流程进度（StudentProcessProgress）

职责：

- 存储学生在某个流程中的当前阶段与历史动作记录

建议关键字段：

- `studentId`、`processType`
- `currentStageId`
- `history[]`（stageId、action、operator、timestamp、remark）

### 通知（Notice）与阅读（NoticeRead）

职责：

- 通知内容、标签、人群规则、发送记录与已读统计

建议关键字段：

- Notice：`id/title/content/tags[]/audienceRule/attachments/publisherId/publishedAt/status`
- NoticeRead：`noticeId/studentId/readAt`

### 申请单与审批记录（Application / ApprovalRecord）

职责：

- 学生提交申请后，后端以申请单为载体流转状态；审批记录记录每一次审批动作与意见

建议关键字段：

- Application：`id/type/applicantId/fields/attachments/status/createdAt`
- ApprovalRecord：`applicationId/approverId/action(comment)/createdAt/nextStatus`

### 导入导出任务（ImportExportJob）

职责：

- 统一管理“上传文件 → 校验 → 入库/导出 → 结果报告”的异步过程

建议关键字段：

- `id/type/inputFile/outputFile/status`
- `errorReportFile`
- `createdBy/createdAt/finishedAt`

## 接口边界（建议按模块拆分）

需求中没有固定 API 设计，本仓库的协作模板给出了示例（见 [角色A-组长下一步行动清单.md](file:///workspace/角色A-组长下一步行动清单.md#L61-L68)）。建议按模块拆分接口域：

- Auth：登录与绑定（token 发放、刷新、退出）
- Notice：通知 CRUD、发布、发送记录、已读上报与统计
- Process：流程定义（配置）、学生进度查询与更新、提醒规则
- Approval：申请单提交、审批工作台、审批动作、结果文件生成与下载
- KnowledgeBase：条目维护、搜索与详情
- ImportExport：上传、任务创建、进度查询、错误报告与结果文件下载
