# 学院学生综合服务与党团管理平台 — 测试手册

> 版本：V2.0  
> 适用：软件工程课程小组互测  
> 服务器地址：**http://10.10.0.22/**

---

## 一、测试前准备

### 1.1 访问 Web 管理端

浏览器打开 `http://10.10.0.22/`，使用已有管理员账号登录：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |

> 如需新建账号：登录后在 **学生管理** 页面点「添加学生」，系统会自动为该学号创建登录账号，密码为 `学号123`。

### 1.2 访问小程序端

小程序需要微信开发者工具或体验版才能运行，操作方式二选一：

**方式 A — 开发者工具（推荐）**
1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用项目代码目录 `D:\software\miniprogram` 打开
3. 详情 → 本地设置 → 勾选「不校验合法域名」
4. 编译运行，输入测试账号登录

**方式 B — 真机体验版**
1. 将自己的微信号发送给项目负责人
2. 负责人登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 成员管理 → 添加体验成员
3. 微信收到邀请后，在「发现 → 小程序」中打开体验版

## 二、测试场景（必测 8 项）

每个场景需同时在 **Web 端操作** 和 **小程序端验证**。

---

### 场景 1 — 通知闭环

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 1.1 | Web | 点击「通知管理」→「新建通知」，输入标题和正文，发布 |
| 1.2 | 小程序 | 切换到「通知」Tab → 下拉刷新 → 看到新通知 |
| 1.3 | 小程序 | 点击通知查看详情 |
| 1.4 | 小程序 | 返回通知列表 → 该通知红点消失（已读） |
| 1.5 | Web | 点击该通知的「统计」按钮 → 看到已读/未读数据 |

**预期结果**：Web 发布 ⇄ 小程序看到 ⇄ 已读反馈到 Web 统计。

---

### 场景 2 — 学生信息同步

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 2.1 | Web | 点击「学生管理」→「添加学生」，填入学号、姓名等 |
| 2.2 | Web | 确认表格中出现新学生，点击「重置密码」获取密码 |
| 2.3 | 小程序 | 用新学号和密码登录 |
| 2.4 | 小程序 | 首页顶部显示姓名、班级、专业 |

**预期结果**：Web 添加学生 ⇄ 小程序可登录并显示个人信息。

---

### 场景 3 — 申请审批闭环

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 3.1 | 小程序 | 服务页 →「证明申请」→ 填写标题和说明 → 提交 |
| 3.2 | Web | 点击「审批工作台」→ 看到新申请，包含申请人姓名 |
| 3.3 | Web | 点击「审批」→ 填写意见 → 点击「通过」 |
| 3.4 | 小程序 | 我的申请 → 刷新 → 状态变为「已通过」 |
| 3.5 | 小程序 | 点击申请查看详情 → 显示审批意见 |

**预期结果**：小程序提交 ⇄ Web 审批 ⇄ 小程序看到结果。

---

### 场景 4 — 党团流程进度

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 4.1 | 小程序 | 服务页 →「党团流程」→ 查看入党各阶段 |
| 4.2 | Web | 点击「党团流程配置」→ 在底部面板输入学生ID（如 `u_s1`）→ 选择下一阶段 → 更新进度 |
| 4.3 | 小程序 | 党团流程页刷新 → 当前阶段前移 |

**预期结果**：Web 更新进度 ⇄ 小程序时间线同步变化。

---

### 场景 5 — 知识库同步

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 5.1 | Web | 点击「知识库管理」→「新建条目」→ 填入标题、标签、内容 |
| 5.2 | 小程序 | 服务页 →「政策搜索」→ 搜索关键词 → 看到新条目 |

**预期结果**：Web 添加知识 ⇄ 小程序可搜索到。

---

### 场景 6 — 文件上传下载

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 6.1 | Web | 点击「知识库管理」→「上传模板文件」→ 选择一个文件 |
| 6.2 | 小程序 | 服务页 →「模板下载」→ 刷新 → 点击下载 |
| 6.3 | Web | 点击「数据导入导出」→ 可看到文件 |

**预期结果**：Web 上传 ⇄ 小程序/浏览器均可下载。

---

### 场景 7 — CSV 学生信息导入

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 7.1 | Web | 点击「数据导入导出」→「下载 Excel 模板」 |
| 7.2 | Web | 用 Excel 编辑 CSV，添加几行学生信息（学号和姓名必填，其余可选） |
| 7.3 | Web | 「选择 CSV 文件并导入」→ 看到成功条数 |
| 7.4 | Web | 切到「学生管理」→ 新学生出现在表格中 |
| 7.5 | 小程序 | 用新导入的学生账号登录 |

**预期结果**：CSV 批量导入 ⇄ 自动创建账号 ⇄ 可登录。

---

### 场景 8 — 权限隔离

| 步骤 | 操作端 | 操作 |
|------|:----:|------|
| 8.1 | 小程序 | 用 student1 登录，提交一条申请 |
| 8.2 | 小程序 | 用 student2 登录，查看「我的申请」 |
| 8.3 | 验证 | student2 **看不到** student1 的申请 |

**预期结果**：学生只能查看自己的数据。

## 四、Web 端功能速查

| 页面 | 能做什么 |
|------|---------|
| 通知管理 | 搜索/发布/编辑/查看详情/已读统计/删除通知 |
| 学生管理 | 按年级/专业/政治面貌筛选，添加/编辑/重置密码/删除 |
| 审批工作台 | 查看待审批申请，通过/驳回/要求补交，下载附件 |
| 党团流程配置 | 编辑入党/入团阶段，更新学生进度 |
| 知识库管理 | 增删改知识条目，上传模板文件 |
| 数据导入导出 | CSV 批量导入学生，导出审批记录 |
| 操作日志 | 查看所有管理操作记录（谁/何时/做了什么/IP） |

## 五、小程序功能速查

| Tab | 能做什么 |
|-----|---------|
| 首页 | 个人信息/快捷入口/常用服务/党团进度/最新通知 |
| 服务 | 政策搜索/模板下载/党团流程/证明申请/请假申请/我的申请 |
| 通知 | 通知列表（下拉刷新/未读红点）/查看详情 |
| 我的 | 个人信息/申请/进度/退出登录 |
